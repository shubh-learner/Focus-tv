# Focus TV Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A personal Android TV app that shows the existing Focus feed in an Apple TV–style glass interface, controlled entirely with a D-pad.

**Architecture:** Add a `/tv` route to the existing Next.js app (server-rendered feed, client interactions) and wrap it in a minimal fullscreen Android WebView APK. Playback uses the official YouTube IFrame Player API. No backend rewrite; only the schema/RLS fixes required by the existing code.

**Tech Stack:** Next.js 14 App Router, TypeScript, Tailwind, Supabase, YouTube Data API v3, Android 11 WebView, Java 17 / Android Gradle Plugin 8.5, Vitest for the spatial-navigation logic.

**Spec:** `docs/superpowers/specs/2026-11-22-focus-tv-design.md`

## Global Constraints

- Target device: MiTV-AXSO2, Android TV 11 (SDK 30), 1080p, WebView 142, no touchscreen, D-pad only. ADB at `192.168.1.3:5555`.
- Apple TV glass tokens: `bg-white/10`, `backdrop-blur-2xl`, `border-white/15`, rounded-2xl/3xl; focus scale `1.06`, ring + glow, `220ms ease-out`; dark ambient background.
- Every TV interactive element is a real `<button>` or `<input>` and carries `data-focusable`. Modals/overlays carry `data-focus-scope`.
- Playback only through `https://www.youtube.com/iframe_api`; never extract streams.
- Videos are 16:9; grid is 4 columns at 1080p; body text ≥ 18px.
- Sections on TV are read-only tabs. No add/rename/delete/reorder on TV.
- Server URL default: `http://192.168.1.28:3000/tv`.
- Keep the desktop `/` and `/login` UI unchanged.
- No new runtime dependencies. `vitest` is the only new dev dependency.
- Never print, commit, or paste the Supabase service-role key or the TV password.

## Review Focus

- **D-pad focus escaping or trapping at grid edges.** Arrow keys must always move to the nearest visible focusable, and must return `null` (no move) at the outer edge instead of jumping to an unrelated control.
- **YouTube iframe blocked in this WebView.** If the embed fails, stop and report; do not silently ship a dead player.
- **Back button exits the app while an overlay is open.** Back must close the topmost modal/player first, and only then navigate back or exit.
- **Expired session on the TV.** `/tv` must redirect to `/tv/login`, never render a blank or stuck dashboard.
- **Overflow with long titles and many sections.** Section pills and video cards must remain readable at 1080p; no clipped or overlapping glass panels.

```js
import fs from "node:fs";
import { createClient } from "@supabase/supabase-js";

// parse .env.local without a dependency
const env = Object.fromEntries(
  fs.readFileSync(".env.local", "utf8").split("\n")
    .filter((l) => l.includes("=") && !l.trim().startsWith("#"))
    .map((l) => [l.slice(0, l.indexOf("=")).trim(), l.slice(l.indexOf("=") + 1).trim()])
);

const password = fs.readFileSync("/tmp/opencode/tv-password", "utf8").trim();
if (password.length < 8) throw new Error("Password must be at least 8 characters");

const admin = createClient(env.NEXT_PUBLIC_SUPABASE_URL, env.SUPABASE_SERVICE_ROLE_KEY, {
  auth: { persistSession: false },
});
const email = process.argv[2];
const { data, error } = await admin.auth.admin.listUsers();
if (error) throw error;
const users = email ? data.users.filter((u) => u.email === email) : data.users;
if (users.length !== 1) throw new Error(`Expected 1 user, found ${users.length}; pass the email`);
await admin.auth.admin.updateUserById(users[0].id, { password });
fs.unlinkSync("/tmp/opencode/tv-password");
console.log(`Password updated for ${users[0].email}`);
```
